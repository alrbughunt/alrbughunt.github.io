01 / About
"Security is not only about finding vulnerabilities — it's about building systems that stay resilient."

I'm a Cyber Security enthusiast and System Administrator with hands-on experience in building, managing, and securing Linux-based infrastructure.

My background combines offensive security and defensive infrastructure. I actively participate in Capture The Flag (CTF) competitions, perform bug hunting, and continuously improve my skills in web security, reconnaissance, and vulnerability assessment.

On the infrastructure side, I build and maintain web servers using Nginx and Apache, deploy monitoring systems such as Wazuh, Grafana, and Cacti, and implement server hardening using IDS/IPS solutions like Fail2Ban, Snort, and PSAD.

I was awarded a cybersecurity scholarship from ID-Networkers and graduated from CodeLamp Batch 1. I have also received security appreciation acknowledgements from several Indonesian platforms and institutions.
